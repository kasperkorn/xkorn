# Dark Theme Demo

This project demonstrates a simple dark theme implementation using HTML, CSS, and JavaScript.

## How to Test

1.  Open the `index.html` file in a web browser.
2.  You should see a page with some sample content and a "Toggle Theme" button.
3.  **Light Theme (Default):**
    *   Verify that the background is light and the text is dark.
    *   Verify the button has its light theme styling.
4.  **Toggle to Dark Theme:**
    *   Click the "Toggle Theme" button.
    *   Verify that the background changes to dark and the text changes to light.
    *   Verify the button has its dark theme styling.
5.  **Toggle Back to Light Theme:**
    *   Click the "Toggle Theme" button again.
    *   Verify that the theme reverts to the light theme.
6.  **Persistence Test:**
    *   Select the dark theme.
    *   Refresh the page.
    *   Verify that the dark theme is still active (it should be remembered from local storage).
    *   Select the light theme.
    *   Refresh the page.
    *   Verify that the light theme is still active.
